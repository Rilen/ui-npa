# Limitações conhecidas

- A paleta clara oficial é Azul Institucional Equilibrado (alternativa A), homologada em 12/11/2026. Ela identifica o UI-NPA e não substitui a marca institucional do NPA.
- As alternativas B e C foram rejeitadas para adoção canônica e permanecem apenas no arquivo histórico.
- A homologação cobre o tema claro do UI-NPA, não uma certificação integral de acessibilidade.
- A seleção disponível é o item ativo da navegação; não existe token separado para seleção de linhas ou itens de conteúdo.
- O tema escuro é experimental e preserva os valores anteriores à homologação. Sombras não foram reajustadas e a demonstração não oferece seletor de tema.
- O mecanismo temporário de comparação de paletas foi removido; não há `candidates.css`, seletor de candidata nem página de comparação no fluxo de produção.
- Reflow foi automatizado com texto a 200% em 390px e 320px. Reflow a 400% não foi validado.
- Não há família tipográfica própria nem ícones como pacote. Os ícones da demonstração são desenhos locais de traço.
- As marcas da demonstração são desenhos fictícios e não representam órgão real.
- React, Angular, PHP e Web Components não estão implementados.
- Dialog, select avançado e tabela complexa não estão implementados.
- A preferência recolhida da sidebar só é aplicada depois que o módulo carrega. Pode haver um instante inicial expandido.
- O breakpoint `48rem` está escrito no CSS e no valor padrão do JavaScript porque media query não recebe custom property.
- Navegadores sem CSS Layers não aplicam a folha como previsto. Internet Explorer não é alvo.
- A demonstração precisa do servidor local. Não há backend, autenticação, API nem dado real.
- A captura visual varia com a fonte do sistema operacional.
- A grade de indicadores usa uma consulta de contêiner nomeada. Navegadores sem suporte caem na composição de uma coluna.
- No mobile, a faixa institucional ocupa duas linhas e é mais alta que no desktop; o cabeçalho da aplicação continua compacto.
- Os testes automáticos não comprovam WCAG 2.2 AA integral.
- Parte da governança não é verificável por teste, conforme a própria política.
- Nenhum pacote foi publicado e nenhum remoto foi atualizado por esta fundação.
